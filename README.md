# Sentinel

Public Manifest V3 Chrome extension from Ted's Lab.

Sentinel pauses suspicious social links and gives an on-device explanation before navigation. The packaged extension is built from the source archive in this repository.

## Chrome Web Store

The package is prepared for Chrome Web Store submission. Publishing the first public item requires a Chrome Web Store developer account and first-time submission through the Chrome Developer Dashboard.

## Privacy

Sentinel scans link and visible post text locally in the browser. It does not send scanned page content to a remote server. Settings use Chrome's local storage.
